## 🛠️ Under the hood

This site is hand-built. No framework and no page builder, just a small generator and a lot of attention to detail.

- **Static and fast:** a Python script turns a few JSON files into plain HTML, CSS, and JavaScript
- **Light and dark:** follows your system theme, with a toggle that remembers your choice
- **Accessible:** keyboard-friendly, reduced-motion aware, and readable contrast in both themes
- **Automated:** every push to `main` builds and deploys through GitHub Actions
- **Hosted on GitHub Pages** at a custom domain, with DNS and email routing on Cloudflare
