# Ray Ali — portfolio

**Live site: [rayali.dev](https://rayali.dev)**

My portfolio of cloud, application, and automation work. It's a hand-built static site with light and dark themes, generated by a small Python script and deployed to GitHub Pages. No framework, no npm install.

## Run locally

```sh
python3 scripts/build.py
python3 -m http.server 8000 --bind 127.0.0.1   # open http://127.0.0.1:8000/
```

## Where things live

| File | What it holds |
|---|---|
| `site.json` | Bio, contact details, services, About page content, and the tech catalog |
| `projects.json` | Featured projects: copy, screenshots, features, and tech stack |
| `groups.json` | Collections of smaller projects, such as Educational Technology |
| `assets/` | Styles, scripts, portraits, and project images |
| `scripts/build.py` | Turns the JSON files into the HTML pages |

Edit the JSON, run the build, and push to `main`. GitHub Actions deploys the site automatically.

## Notes

- Every technology a project lists must exist in the `tech` catalog in `site.json`, or the build stops and names the missing one.
- With `cwebp` installed (`brew install webp`), the build creates WebP copies of screenshots. Commit them; CI uses the committed copies.
- Experience and certifications on the About page appear once filled in under `experience` and `certifications` in `site.json`.
- Project READMEs used as source material (`assets/*/README*.md`) are git-ignored and never published.

## Hosting

GitHub Pages with a custom domain (`rayali.dev`, DNS on Cloudflare). `itsrayali.github.io` redirects to it.
